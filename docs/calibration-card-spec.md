# Calibration Card Specification

The MirrorStep calibration card is a 100 mm by 60 mm matte card. It has four 10 mm, high-contrast square markers inset 2.8 mm from each corner. The card must be flat on the same floor plane as the foot, fully visible, and must not overlap the foot.

The system checks the card quadrilateral, perspective consistency, full-frame visibility, overlap risk, and all four corner markers. A calibration-card scale result is available only when the existing measurement/capture gates pass and marker confidence is at least 0.90.

This card is the supported high-confidence web capture path. It does not make no-reference RGB measurement trustworthy, and it does not replace real-device benchmark evidence.
